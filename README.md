# Wolf IPTV – iPhone uygulaması (PC'siz, ev dışında da çalışır)
Uygulama IPTV sağlayıcısına doğrudan bağlanır: Wi‑Fi ya da mobil veriyle her yerde çalışır.
Her `push`ta GitHub Actions imzasız `WolfIPTV.ipa` derler (Releases → ios-latest).
Kurulum: PC'de Sideloadly (ya da AltStore) → iPhone kabloyla → IPA'yı Apple kimliğinle yükle.
Ücretsiz Apple kimliğinde imza 7 gün geçerlidir; evde PC açıkken yenilenir.
