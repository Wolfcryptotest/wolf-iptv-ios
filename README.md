# Wolf IPTV – iPhone uygulaması (PC'siz)
Her `push`ta GitHub Actions imzasız `WolfIPTV.ipa` derler (Releases → ios-latest).
Kurulum: PC'ye AltServer kur → iPhone'u kabloyla bağla → AltStore ile IPA'yı Apple kimliğinle yükle.
AltStore, PC açık ve aynı Wi‑Fi'dayken uygulamayı 7 günde bir kendiliğinden yeniler.
